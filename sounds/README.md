# 内置音效

这些 wav 由 scripts/generate-sounds.mjs 合成，不要手改文件本身。整包是柔和、接近手机系统提示音的方向：软起音、铃/木琴/卡林巴/水滴，少量房间混响，无采样。

## 试听

直接双击 wav，或在侧边栏 插件 → dsh-bing 详情页的配置区里逐个试听。

## 修改

1. 改 scripts/generate-sounds.mjs 里对应的配方；
2. 如果增删音效，同时改 sounds/catalog.json（id、文件名、名称、场景、时长、rms）；
3. 运行 npm run sounds；
4. 运行 npm run sounds:check，确认时长/RMS/格式，并确认重新合成与已提交文件逐字节一致；
5. 提交 catalog.json 与新的 wav。

## 约定

- 44.1kHz、单声道、16-bit PCM；SoundPlayer 对格式很挑，别改成别的。
- 响度按 catalog.json 的 rms 字段（0.12–0.13）归一化，峰值封顶 0.95；短音靠峰值补偿，长音靠 RMS 保持不吵。
- 首尾淡入淡出，避免爆音。
- 时长控制在 2 秒内（当前 0.8–1.9 秒）；通知本身只有几秒，长音效会被 8 秒封顶截断。
- 保留少量房间混响和 3ms/80ms 淡入淡出；目标是柔和，不是干净到发干。
- 苹果/华为的原始系统音效有版权，不要把这些文件直接放进仓库；用户自己的文件走自定义导入。
- 文件名只用小写字母、数字、连字符，保持 01- 前缀便于排序。
